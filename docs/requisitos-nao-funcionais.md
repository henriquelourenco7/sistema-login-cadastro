# Requisitos Nao Funcionais

### RNF01 - Backend

O backend deve ser desenvolvido utilizando Java e Spring Boot.

### RNF02 - Frontend

O frontend deve ser desenvolvido utilizando HTML, CSS e JavaScript.

### RNF03 - Banco de dados

O sistema deve utilizar MySQL.

### RNF04 - API

O backend deve disponibilizar uma API REST para comunicacao com o frontend.

### RNF05 - Persistencia

O sistema deve utilizar JPA/Hibernate para trabalhar com o banco de dados.

### RNF06 - Seguranca

As senhas nao devem ser armazenadas em texto puro no banco de dados.

### RNF07 - Validacao

Os dados recebidos pelo sistema devem ser validados antes de serem processados.

### RNF08 - Controle de acesso

O sistema deve controlar as permissoes de acordo com o tipo de usuario.

### RNF09 - Versionamento

O projeto deve utilizar Git para controle de versao.
