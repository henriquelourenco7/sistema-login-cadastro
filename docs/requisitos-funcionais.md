# Requisitos Funcionais

## Cadastro

### RF01 - Cadastrar usuario

O sistema deve permitir que uma pessoa crie uma conta informando nome, email, telefone, data de nascimento e senha.

### RF02 - Validar cadastro

O sistema deve verificar se os dados informados no cadastro sao validos.

### RF03 - Verificar email

O sistema deve verificar se o email ja esta cadastrado.

### RF04 - Verificar telefone

O sistema deve verificar se o telefone ja esta cadastrado.

## Login

### RF05 - Realizar login

O sistema deve permitir que o usuario faca login utilizando email e senha.

### RF06 - Validar login

O sistema deve verificar se o email e a senha estao corretos.

### RF07 - Verificar status da conta

O sistema deve verificar se a conta esta ativa antes de permitir o login.

## Recuperacao de senha

### RF08 - Recuperar senha

O sistema deve permitir que o usuario solicite a recuperacao da senha informando email e data de nascimento.

### RF09 - Criar nova senha

O sistema deve permitir que o usuario defina uma nova senha apos a recuperacao.

## Alteracao de dados

### RF10 - Alterar email

O sistema deve permitir que o usuario logado altere seu email.

### RF11 - Alterar telefone

O sistema deve permitir que o usuario logado altere seu telefone.

### RF12 - Alterar senha

O sistema deve permitir que o usuario logado altere sua senha.

## Administracao

### RF13 - Bloquear usuario

O sistema deve permitir que um administrador bloqueie um usuario comum.

### RF14 - Desbloquear usuario

O sistema deve permitir que um administrador desbloqueie um usuario comum.

### RF15 - Banir usuario

O sistema deve permitir que um administrador bana um usuario comum.

### RF16 - Desbanir usuario

O sistema deve permitir que um administrador desbane um usuario comum.
